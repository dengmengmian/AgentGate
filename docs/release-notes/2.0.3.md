## MuxLayer 2.0.3 — OrcaRouter support

This release adds OrcaRouter as a built-in provider. 本版本新增 OrcaRouter 作为内置 Provider。

### Added / 新增

- **OrcaRouter** —— An OpenAI-compatible aggregator: one key, 190+ models from OpenAI, Anthropic, Google, DeepSeek, Qwen, Kimi and others. Pick it in Add Provider and the base URL `https://api.orcarouter.ai/v1` is filled in for you; paste a key starting with `sk-orca-` into Quick Add and it is recognised without picking anything. OpenAI 兼容的聚合网关，一个 key 覆盖 OpenAI、Anthropic、Google、DeepSeek、通义、Kimi 等 190+ 模型。在「添加 Provider」里选它，Base URL `https://api.orcarouter.ai/v1` 会自动填好；在「快速添加」里粘贴 `sk-orca-` 开头的 key，不用选类型也能识别出来。
- The default model is `orcarouter/auto`, the per-account router OrcaRouter creates at signup — it sizes the model to each request instead of pinning one. The full model list is fetched from OrcaRouter when you add the provider, so it never goes stale in MuxLayer. 默认模型是 `orcarouter/auto`，即 OrcaRouter 在注册时为每个账号创建的路由，按每次请求的难度挑模型，而不是固定一个。完整模型列表在添加 Provider 时从 OrcaRouter 拉取，不会在 MuxLayer 里过期。

### Notes / 说明

- Nothing else changed. OrcaRouter needed no gateway, protocol, or adapter work — it slots in through the existing provider catalog. 其他没有改动。OrcaRouter 不需要网关、协议或适配层的改动，走现有 Provider 目录即可接入。
