## MuxLayer 2.0.4

This release is about wiring more coding agents, using the MuxLayer name, and fixing a few sharp edges we hit while doing that.

本版主要是多接几个客户端、名字统一成 muxlayer，以及用的时候踩到的坑。

### Clients / 客户端

- **One-click Kimi CLI, Grok Build, and DeepSeek Harness.** Apply from the Clients page. Each client now has its own icon so you can tell them apart. 客户端页可以一键接入这三家。图标也换成各自的样子，不再长得一样。
- **Apply can stop a running client.** If the tool is still open, click **Stop process** instead of copying a `kill` command. Nothing is killed unless you click. 应用完如果那个客户端还在跑，可以直接「结束进程」，不用自己复制 kill。不会偷偷杀。
- **Kimi writes the folder it actually reads.** Current Kimi Code uses `~/.kimi-code`, not the old `~/.kimi`. The MuxLayer model also includes a context size, so Kimi can start a session. Kimi 现在写到 `~/.kimi-code`。模型补上了上下文长度，不会再卡在「必须填写 max_context_size」。

### Names / 名字

- **The virtual model is `muxlayer`.** Send `muxlayer` and MuxLayer picks the real model from the current route. Configs that still say `agentgate` keep working. 虚拟模型统一叫 `muxlayer`。以前写的 `agentgate` 仍然认。

### Routing and tools / 路由和工具

- **Route templates** for task split, local-first, and cloud-first, so you don't start from a blank route. 路由模板：任务拆分、本地优先、云端优先。
- **MCP and Skills** can manage OpenCode and Gemini too. MCP / Skills 也能管 OpenCode 和 Gemini。
- **Several API keys** show as "N keys · round-robin". MuxLayer does not invent a quota per key. 多把 Key 只显示「N 把 key · 轮转」，不会编造每把的额度。

### Other / 其它

- Prefer `MUXLAYER_*` environment variables; `AGENTGATE_*` still works. Docker writes both names. 环境变量优先 `MUXLAYER_*`，旧的 `AGENTGATE_*` 还能用。Docker 两种名字都会写。
- Overview shows cache hit rate. 概览能看到缓存命中率。
- The website has a comparison with cc-switch and CCR. 官网加了和 cc-switch、CCR 的对比。
- The app is a bit lighter: smaller sidebar logo, slower gateway polling, command palette loads when you open it. 界面轻一点：侧栏 logo 换成小图，顶栏不用三秒刷一次网关，命令面板打开才加载。
