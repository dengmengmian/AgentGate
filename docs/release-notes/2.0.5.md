## MuxLayer 2.0.5

This release fixes Codex 0.152+ being unable to run shell when the model behind MuxLayer is DeepSeek (or another Chat Completions / Anthropic / Gemini upstream).

本版修复 Codex 0.152+ 经 MuxLayer 接 DeepSeek（以及 Chat Completions / Anthropic / Gemini 上游）时跑不了 shell。

### Fixed / 修复

- **Codex shell / `exec`.** Codex 0.152+ sends the code-mode `exec` tool inside a `functions` namespace instead of as a top-level custom tool. MuxLayer used to pass that request through to DeepSeek's Responses API, which does not accept `exec`. The model then had no shell, and a JSON `function_call` for `exec` was rejected by `codex_core::tools::router`. MuxLayer now converts the call and returns a `custom_tool_call` with the raw JavaScript Codex expects. Codex 0.152+ 把 code-mode 的 `exec` 包在 `functions` 命名空间里。MuxLayer 以前会直通给 DeepSeek Responses，上游不认 `exec`，模型就没有 shell；就算模型用 JSON function 去调，Codex 的 router 也会拒。现在会走转换路径，回给 Codex 的是带原始 JavaScript 的 `custom_tool_call`。
