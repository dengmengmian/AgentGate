## MuxLayer 2.0.2 — Windows popup loop fix

If you clicked "Apply config" on Windows and black `tasklist.exe` windows started popping up nonstop — this release fixes that. Windows 用户点「应用配置」后黑色 `tasklist.exe` 窗口无限弹出的问题，这个版本修复了。

### What happened / 问题原因

- MuxLayer checks whether your CLI (Codex, Claude Code, …) is still running so it can remind you to restart it after a config change. On Windows that check spawned `tasklist` in a visible console window. MuxLayer 会探测你的 CLI 是否还在运行，以便在改完配置后提醒重启；Windows 下这个探测会弹出一个可见的控制台窗口。
- The popup stole focus; when it closed, focus returned to MuxLayer, which refreshes on focus — triggering the check again. Result: an endless loop of black windows. 弹窗抢走焦点，关闭后焦点回到 MuxLayer，又触发一次「获得焦点即刷新」的探测，于是黑窗无限循环。

### Fixed / 修复

- Process detection and the "Restart Codex Desktop" button now run their system commands with a hidden console. No more black windows, no more loop. 进程探测与「重启 Codex Desktop」的系统命令改为隐藏控制台执行，不再弹黑窗、不再循环。

macOS and Linux are unaffected; nothing else changed in this release. macOS 与 Linux 不受影响，本版本无其他改动。
